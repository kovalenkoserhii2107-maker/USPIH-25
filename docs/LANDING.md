# Публічний лендинг застосунку

Адреса після публікації GitHub Pages:
https://kovalenkoserhii2107-maker.github.io/USPIH-25/landing.html

Сторінка продає застосунок трьом аудиторіям: правлінню, бухгалтерам і
мешканцям. Мова проста: без «КЕП», «ОСВ» і «XML» там, де можна сказати
«підпис голови», «відомість» і «файл для податкової».

## Будова (зверху вниз)

1. **Перший екран** — обіцянка одним реченням, дві кнопки, три гарантії,
   чотири факти (щогодини, 0 грн без підпису, 11 кроків, 3 кабінети).
2. **Для кого** — вкладки «Правління · Бухгалтер · Мешканець»: що було,
   пʼять вигод простими словами й екрани. Посилання `#roles-board`,
   `#roles-acc`, `#roles-res` відкривають потрібну вкладку одразу.
3. **Як це працює** — два шляхи грошей по чотири кроки: внесок мешканця
   й оплата постачальнику.
4. **Можливості** — 12 карток за модулями застосунку.
5. **Зразок квитанції** з QR (умовні дані, QR веде на саму сторінку).
6. **Безпека**, **Запуск** (4 кроки), **Контакти** із заявкою, **Питання**.

## Дві компоновки

- **Компʼютер** (від 981 px): дві колонки, на першому екрані — вікно
  бухгалтерії поруч із телефоном мешканця, можливості розгорнуто сіткою.
- **Телефон** (до 680 px): одна колонка, у центрі першого екрана —
  кабінет мешканця, вкладки ролей прилипають під шапкою, можливості
  згорнуто в список, унизу — панель «Подзвонити / Залишити заявку»
  (зʼявляється після першого екрана й ховається біля форми).
- Між ними (681–980 px) — планшет: одна колонка без панелі дій. Меню
  шапки згортається в кнопку вже від 1100 px.

## Екрани

- Правління й мешканець — справжні знімки з `assets/landing/` (WebP,
  1600×1000 і 600×1299), зроблені на локальному стенді з умовними даними:
  квартири «Власник Тестовий N», постачальники «(демо)». Натиск на знімок
  у «Для кого» збільшує його.
- Бухгалтерія («Сьогодні», банк, шлях платежів, закриття місяця) зібрана
  з блоків HTML і CSS (`.win`, `.v-card`, `.bento`): вони чіткі на будь-якому
  екрані й не старіють разом зі знімками. Дані там теж умовні; блоки
  позначено `aria-hidden`, зміст продубльовано текстом поруч.
- Новий знімок: файл `assets/landing/<назва>.webp` і `<img>` у пристрої
  `.device.phone` або `.device.laptop`.

## Скрипт і стилі

`js/landing.js` — лише локальні ефекти: тінь і меню шапки, нахил першого
екрана за курсором, поява блоків, вкладки ролей, крапка на шляху грошей,
згортання можливостей на телефоні, збільшення знімка, заявка, панель дій.
Без JavaScript сторінка читається повністю (видно панель правління, усі
можливості розгорнуті). За `prefers-reduced-motion` рухи вимикаються.
Сторінка не вантажить Firebase, сторонні шрифти чи бібліотеки.

Перевірка: `npm run ci` і перегляд на ширинах 390, 768, 1024, 1280 і
1440 px — без горизонтальної прокрутки.

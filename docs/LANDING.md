# Публічний лендинг застосунку

Адреса після публікації GitHub Pages:
https://kovalenkoserhii2107-maker.github.io/USPIH-25/landing.html

Сторінка представляє застосунок мешканцям інших будинків, головам
правління та бухгалтерам. Каталог охоплює 30 груп можливостей:
8 для мешканця, 10 для правління, 12 для бухгалтера. Опис міститься
безпосередньо в `landing.html`, тому доступний без JavaScript.

Галерея має 10 екранів із поточних HTML/CSS/JS застосунку. Знімки в
`assets/landing/` зроблені з адаптерами демонстраційних даних із тестового
циклу обліку. Дані робочого Firebase, справжні банківські операції та
персональні дані мешканців для знімків не використовувалися. Мобільні
зображення також використовуються у першому екрані й розділах ролей.

`js/landing.js` керує розгортанням описів, відбором галереї та збільшенням
знімків у діалозі. Escape закриває діалог і повертає фокус до зображення.
Без JavaScript працюють посилання, описи й звичайне відкриття картинок;
кнопки фільтрів і масового розгортання зʼявляються після запуску скрипту.
`style-landing.css` підключається лише до лендингу. Сторінка не завантажує
Firebase SDK, кабінети, сторонні шрифти або бібліотеки; зображення нижче
першого екрана завантажуються відкладено.

Для редагування: тексти, можливості, FAQ і посилання — у `landing.html`;
зовнішній вигляд — у `style-landing.css`; знімки — у `assets/landing/`.
Сторінка включена в `scripts/build-site.mjs` і публікується наявним
workflow GitHub Pages разом із застосунком.

Новий будинок потребує окремого впровадження та налаштування даних.
Кнопка «Запуск у вашому ОСББ» веде до опису цього процесу. Контакт для
заявок не заданий; форма, яка імітує надсилання заявки, не створювалася.
Після визначення контакту можна додати посилання на email, Telegram
чи інший канал звʼязку.

Перевірка: `node --check js/landing.js`, `npm run check`, `npm run build`
і сценарії браузера на ширинах 320, 390, 768 та 1280 px. Перевіряються
переходи, розгортання всіх описів, фільтри, перегляд зображень, Escape,
повернення фокуса, посилання на файли, відсутність горизонтального
переповнення й запитів до бекенду. Окремо перевіряється читання без JS.

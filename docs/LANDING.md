# Публічний лендинг застосунку

Адреса після публікації GitHub Pages:
https://kovalenkoserhii2107-maker.github.io/USPIH-25/landing.html

Сторінка показує застосунок мешканцям, правлінню й бухгалтерам інших
будинків. Будова: перший екран (компʼютер і два телефони з живими
екранами), три картки ролей, три «розповіді» ролей, ланцюжок однієї
оплати, безпека й цифри, порядок запуску, питання.

Розповідь ролі — кроки ліворуч і прилиплий пристрій праворуч: коли крок
доходить до середини екрана, знімок плавно змінюється, а пристрій
перемикається між ноутбуком і телефоном. Поки гортаєте розповіді, вгорі
тримається перемикач «Мешканець · Правління · Бухгалтер». На телефоні
прилипання немає: знімок стоїть у самому кроці.

Знімки в `assets/landing/` (WebP) зроблено на локальному стенді з
емуляторами Firebase і тестовими даними: умовні квартири «Власник
Тестовий N» і постачальники з позначкою «(демо)». Дані робочого Firebase
і персональні дані мешканців не використовувалися.

`js/landing.js` — лише локальні ефекти: поява блоків, прогрес прокрутки,
легкий паралакс першого екрана, зміна знімків за кроками, перемикач
ролей, анімація ланцюжка й цифр, збільшення знімка в діалозі. Без
JavaScript сторінка читається повністю. За `prefers-reduced-motion`
анімації вимикаються. Сторінка не вантажить Firebase, сторонні шрифти
чи бібліотеки; шрифт системний.

Для редагування: тексти — у `landing.html`, вигляд — у
`style-landing.css`, знімки — у `assets/landing/`. Новий знімок: той
самий розмір (1600×1000 для компʼютера, 600×1299 для телефона) і
атрибут `data-shot` і в кроці, і в пристрої-сцені.

Перевірка: `npm run ci` і перегляд на ширинах 390, 768, 1280 і 1440 px.

# Публічний лендинг застосунку

Адреса після публікації GitHub Pages:
https://kovalenkoserhii2107-maker.github.io/USPIH-25/landing.html

Сторінка продає застосунок правлінням і бухгалтерам інших будинків.
Будова (зверху вниз, ~7 300 px на компʼютері, ~10 000 px на телефоні):
перший екран із компʼютером і двома телефонами, чотири цифри
результату, «Було → стало», екскурсія по кабінетах, можливості,
зразок квитанції, безпека, запуск із заявкою, питання, фінальний заклик.

Екскурсія — вкладки «Бухгалтер · Правління · Мешканець». Пункт списку
міняє знімок поруч (компʼютер або телефон, атрибут `data-device`).
Знімок вантажиться лише тоді, коли його відкрили; натиск на екран
збільшує його в діалозі. На телефоні список — горизонтальна стрічка
під знімком. Прилипання й «сцен прокрутки» немає: блоки читаються
одразу, тож картинки не зникають і не лишаються порожніми.

Зразок квитанції повторює квитанцію застосунку. Дані умовні: кв. 45
«Власник Тестовий 45», реквізити приховано; QR веде на саму сторінку.

Знімки в `assets/landing/` (WebP) зроблено на локальному стенді з
емуляторами Firebase і демо-прогоном бухгалтерії: умовні квартири
«Власник Тестовий N», постачальники з позначкою «(демо)», демо-збори й
звернення. Дані робочого Firebase і персональні дані мешканців не
використовувалися. Розміри: 1600×1000 (компʼютер) і 600×1299 (телефон).
Новий знімок: файл `assets/landing/<назва>.webp` і пункт екскурсії з
`data-shot="<назва>"`.

Кнопка «Залишити заявку» (`data-contact` у розділі «Запуск») — лист без
адресата; впишіть сюди контакт для заявок (пошта, телефон чи Telegram).

`js/landing.js` — лише локальні ефекти: тінь шапки, нахил першого екрана
за курсором, поява карток, вкладки й знімки екскурсії, збільшення
знімка. Без JavaScript сторінка читається повністю (видно кабінет
бухгалтера). За `prefers-reduced-motion` анімації вимикаються. Сторінка
не вантажить Firebase, сторонні шрифти чи бібліотеки.

Перевірка: `npm run ci` і перегляд на ширинах 390, 768, 1280 і 1440 px.

# Демо-будинок

`demo.html` — вхід у застосунок без реєстрації для потенційних клієнтів:
голова правління, бухгалтер, член правління або мешканець кв. 7 умовного
будинку на 300 квартир. Посилання з лендингу: «Спробувати демо» та
«Спробувати в демо як …» біля кожної ролі (`demo.html?role=chair|accountant|board|resident`).

## Як це влаштовано

- **Нічого не зберігається.** Firebase у вкладці з позначкою демо підмінено:
  база — у памʼяті сторінки (`js/demo/memdb.js`), серверні функції —
  справжній код `functions/*`, зібраний для браузера (`_site/js/demo/server.js`).
  Дії працюють (погодження, рознесення, платежі на підпис через тестовий
  Приват24, голосування), але після перезавантаження будинок знову як на
  початку. Кожен відвідувач має власну копію — до робочої бази й до інших
  відвідувачів зміни не доходять.
- **Перемикач.** `demo.html` ставить у `sessionStorage` позначку `uspih_demo`
  з роллю. Короткий скрипт на початку `index.html`, `admin.html`, `buh.html`,
  `platform.html`, `accounting-test.html` бачить її й додає import map:
  `firebase-*.js` з gstatic → `js/demo/fb-*.js`. Без позначки сторінки
  працюють як завжди. «Вийти з демо» знімає позначку.
- **Годинник.** «Сьогодні» в демо — 20.01.2026 (`js/demo/clock.js` і той
  самий рядок у скрипті сторінок): дані завжди «свіжі» відносно дати на екрані.
- **Панель «Демо»** (`js/demo/bar.js`) — хто ви, інша роль, почати заново, вийти.

## Звідки дані

`npm run build` збирає демо-будинок тим самим серверним кодом
(`scripts/demo/seed.mjs` → `_site/js/demo/seed.json`):

1. перенос бази тестової бухгалтерії (303 приміщення, власники, залишки) і
   три закриті місяці — жовтень–грудень 2025: нарахування, документи,
   виписка, зарплата, звірка, закриття, звіт мешканцям;
2. січень 2026: нарахування, три постачальники «(демо)» з договорами,
   документ на погодженні голови, платіж на підписі, оплати мешканців і
   незрозумілі надходження в «Рішеннях», чернетка відомості зарплати,
   подані звіти й кошторис 2026;
3. правління й мешканці: загальні збори з голосами, опитування, оголошення,
   звернення, чат, стан світла.

Імена людей і назви контрагентів умовні. Якщо крок наповнення падає,
збірка зупиняється з назвою кроку — демо не публікується зламаним.

Серверний код у браузері отримує заглушки замість Node і Firebase Admin
(`scripts/demo/shims/*`): `crypto` (SHA-256/SHA-1), `zlib` (fflate),
Storage і Auth у памʼяті, сповіщення вимкнено.
